# 3.0.0

## What's new

This is a major release that ports a long-running fork's features into the
mainline plugin while preserving full backwards compatibility for existing
configurations.

### New commands

| Command | Default keybinding (macOS) | Default keybinding (Linux/Windows) |
|---|---|---|
| `Open URL: Select URL` | `ctrl+shift+u` | `ctrl+alt+shift+u` |
| `Open URL: Copy Deep Link` | `ctrl+alt+shift+u` | `ctrl+alt+shift+d` |
| `Open URL: Paste Relative Path` | `ctrl+alt+v` | `ctrl+alt+v` |
| `Open URL: Copy Transformed Path` | `ctrl+alt+shift+c` | `ctrl+alt+shift+c` |

The original `open_url` command on `ctrl+u` (macOS) / `ctrl+alt+u`
(Linux/Windows) is unchanged.  All keybindings remain gated by the existing
`disable_default_key_bindings` setting.

### Deep links

Open URL now understands `path:line`, `path:"search text"`, and
`path:/regex/` deep-link syntax.  Selecting `~/notes.md:42` and running
**Open URL** opens the file at line 42.  **Copy Deep Link** writes the
inverse format from the cursor or selection.

Set `deep_link_line_number_only: true` to restrict deep links to line
numbers only.

### Multi-line selection

Selecting multiple non-empty lines under a single cursor now opens each line
as its own URL/path, in addition to the existing multi-cursor support.

### `autoactions`

The new `autoactions` setting matches files by `endswith` or `pattern` and
auto-selects an action label from your `*_custom_commands` lists, either
firing it immediately (`action: "auto"`) or pre-highlighting it in the
menu (`action: "menu"`).

### Built-in command sentinels

`commands` may now be a reserved string instead of a shell argv:

| Sentinel | Behavior |
|---|---|
| `"edit_in_sublime"` | Open the file in Sublime, honoring any deep-link suffix |
| `"open_in_new_window"` | Open the path in a new Sublime window |
| `"system_open"` | Hand off to the OS (`open`, `xdg-open`, `cmd /c start`) |
| `"add_to_project"` | Append the folder to the current Sublime project |

### Per-opener fields

`*_custom_commands` entries gain three optional fields:

- `terminal: true` — wrap the command in xterm/cmd.exe.
- `pause: true` — append a "press ENTER" pause (paired with `terminal`).
- `pre_command: "sh"` — prepend an interpreter to the argv.

### `browser_search` shortcut

A simpler counterpart to `web_searchers`: a single search-engine URL
template with `{query}`.  When `web_searchers` is empty and this is set,
search opens directly without a panel.

### File-URI support

`file://...` URIs (including `file:///`, `file://localhost/`, and
percent-encoded forms) are recognized as local paths anywhere a URL can be
selected.

## Defaults overhaul

Default `file_custom_commands` and `folder_custom_commands` now ship with
a richer baseline menu that mirrors what most users would build by hand:

- Files: edit, run, reveal, open in new window, system open
- Folders: open in new window, reveal, add to project

Default `autoactions` make `.txt`, `.md`, `.log`, `.config`,
`.sublime-settings`, and `.sublime-project` files auto-edit, and on
Windows make `.exe`/`.com` auto-run while `.bat`/`.cmd` open the menu
pre-highlighting "run".

## Compatibility

If you've customized `file_custom_commands`, `folder_custom_commands`, or
`other_custom_commands` in your User-folder settings or your
`.sublime-project`, those values continue to win — the overhauled defaults
only show up for users who haven't customized them.

To restore the previous defaults, copy them into your User-folder
`open_url.sublime-settings`:

```jsonc
{
  "browser_search": "",
  "file_custom_commands": [
    { "label": "reveal", "os": "osx", "commands": ["open", "-R"] },
    { "label": "open with default application", "os": "osx", "commands": ["open"] },
    { "label": "reveal", "os": "windows", "commands": ["explorer", "/select,"] },
    { "label": "open with default application", "os": "windows", "commands": ["start"], "kwargs": { "shell": true } },
    { "label": "reveal", "os": "linux", "commands": ["nautilus", "--browser"] },
    { "label": "open with default application", "os": "linux", "commands": [] }
  ],
  "folder_custom_commands": [
    { "label": "reveal", "os": "osx", "commands": ["open"] },
    { "label": "reveal", "os": "windows", "commands": ["explorer"] },
    { "label": "reveal", "os": "linux", "commands": ["nautilus", "--browser"] }
  ],
  "autoactions": []
}
```
